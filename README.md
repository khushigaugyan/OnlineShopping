# Online Shopping Calculator

## Overview

The **Online Shopping Calculator** is a desktop application developed using **Core Java**, **Swing**, and **AWT**. It simulates a simple shopping system where users can select products, specify quantities, and calculate the total bill through an easy-to-use graphical interface.

## Features

* User-friendly graphical interface
* Product selection
* Quantity input
* Automatic bill calculation
* Displays total purchase amount
* Simple desktop application built using Core Java

## Tech Stack

* Core Java
* Java Swing
* Java AWT


## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA, Eclipse, or NetBeans.
3. Compile and run the main Java file.
4. Use the application to select products and calculate the final bill.
